    About This Project

    This Weather Viewer is a comprehensive portfolio project I built to demonstrate my proficiency with modern front-end web technologies. I utilized HTML5, CSS3 (including Flexbox and Grid layouts), and vanilla JavaScript (ES6+ features like async/await and modules).

    The application allows users to search for cities worldwide, view real-time weather conditions, analyze detailed 5-day forecasts with interactive charts, and manage a personalized list of favorite locations persisted via the browser's Local Storage.

    Key Features & Technologies

    • Asynchronous JavaScript: I implemented complex data fetching logic using the Fetch API to retrieve weather data and background images in parallel without blocking the UI.
    • Dynamic DOM Manipulation: All content, from the weather cards to the news feed, is generated dynamically based on API responses.
    • Data Visualization: I integrated Chart.js to render visual trends for temperature and precipitation probabilities.
    • Geolocation API: I leveraged the browser's native API to offer a seamless "Locate Me" feature.
    • Responsive Design: The layout adapts fluidly to different screen sizes, ensuring a consistent experience on mobile and desktop.
